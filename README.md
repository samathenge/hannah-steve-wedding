# Hannah & Steve — wedding invitation

Single-page invitation for Saturday, 28 November 2026, 10:00 AM, A.I.C Mwariki Church, Pipeline, Nakuru, Kenya.

Built with TanStack Start, React, TypeScript and Tailwind CSS.

## Run locally

```sh
npm install   # or: bun install
npm run dev
```

## Where things are

- `src/routes/index.tsx` — all the content, RSVP numbers, countdown and `SITE_URL`
- `src/styles.css` — colours, fonts and layout
- `public/photos/` — the four photos (names are listed in `src/lib/photos.ts`)
